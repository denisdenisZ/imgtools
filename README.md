# imgtool

A C library and toolset for processing raw Bayer sensor images.

## Modules

### `img` — Core image types

Defines the two central data structures used throughout the project:

- `st_raw_bayer_img` — a raw sensor frame with full metadata: bit depth, Bayer pattern, packing, bit alignment, endianness, stride, embedded line counts, black level, and companding info.
- `st_norm_bayer_img` — a normalized view of the same frame where every pixel has been unpacked into a `uint32_t`, endianness corrected, and bit-aligned to LSB.

Key functions: `create_img` (load from file into `st_raw_bayer_img`), `normalize_img` (produce `st_norm_bayer_img` from raw).

---

### `img_math` — Math utilities

Header-only (`include/math/`), all `static inline`.

- `pow2_u32(n)` — `1U << n`
- `get_mrv(bits)` — maximum representable value for a given bit depth
- `log2_pow2(val)` — integer log₂ for power-of-two values via count-trailing-zeros
- `best_fixed_u32` / `from_fixed_to_double` — find the best fixed-point representation of a double within a given bit budget
- `calc_slope` / `point_slope_lerp` — piecewise-linear building blocks

**`fxdpoint.h`** — fixed-point arithmetic (`st_ufxd_t`):
`to_fixed`, `from_fixed`, `fxd_mul`, `fxd_normalize`, `fxd_add`, `fxd_sub`, `fxd_mul_and_norm`. Useful for tone-mapping hot paths where floating point is undesirable.

---

### `img_dcmp` — Companding / decompanding

PWL (piecewise-linear) tone curve representation and application.

- `st_pwl` — stores x/y keypoints and precomputed slopes
- `init_pwl` / `copy_pwl` / `free_pwl` — lifecycle
- `calc_slopes` — precompute slopes from keypoints
- `comp_decomp` — apply a PWL to an array of `double` values
- `pwl_reverse` — invert a PWL (e.g. turn a companding curve into a decompanding curve), handles clipped segments
- `apply_comp_decomp(st_norm_bayer_img *, const st_pwl *)` — apply a PWL to every pixel of a normalized image in-place; updates `img->bpp` to the output bit depth (`pwl->bpp_y`)

---

### `img_io` — File I/O

- `read_file` / `write_file` — generic byte-buffer file I/O with detailed error codes

**PGM output** (`include/io/pgm.h`):
- `write_pgm(filename, img)` — write a `st_norm_bayer_img` as a 16-bit binary PGM (P5). Pixels are scaled from the image's native bit depth to the full 0–65535 range.
- `write_pgm_heatmap(filename, img)` — write the complement of each pixel (`max - value`) as a PGM. Saturated pixels (at max) appear black; pixels far below max appear bright. Used to spot underexposed regions or verify that a tone curve reaches the top of the output range.

---

### `img_gen` — Synthetic test image generation

Generates raw Bayer test images using the same `st_raw_bayer_img` type as the rest of the pipeline.

**Core** (`include/img_gen/img_gen.h`):
- `alloc_gen_img` / `free_gen_img` — allocate a blank image with sane defaults (LE, LSB-aligned, unpacked)
- `transform_img` / `transform_img_xy` — apply a per-pixel callback across the whole image; the XY variant also passes the Bayer channel (R/Gr/Gb/B) at each position
- `write_pixel_le` / `read_pixel_le` — byte-level little-endian pixel access
- `get_bayer_channel_at(pattern, x, y)` — returns which Bayer channel a given pixel belongs to, covering all patterns defined in `image.h`

**Patterns** (`include/img_gen/basic_patterns.h`):
- `set_min` / `set_max` — fill every pixel with 0 or the full-scale value for the image's bit depth
- `set_linear_gradient` — ramp from 0 to max across all pixels in raster order
- `set_linear_gradient_per_channel` — independent 0-to-max ramp per Bayer channel (R, Gr, Gb, B each sweep their own range)
- `set_checkers(img, num_pax_x, num_pax_y, invert)` — configurable checkerboard pattern

**Factory** (`include/img_gen/imgfactory.h`):
- `create_image(width, height, bpp, bayer_pattern, pattern, filename, opts)` — one-call interface; generates the image and writes the raw file

---

### `src/apps/img_gen_app`

Standalone executable that generates six reference raw files at 1920×1080 16bpp:

| File | Pattern |
|---|---|
| `MIN_16bpp.raw` | All pixels at 0 |
| `MAX_16bpp.raw` | All pixels at 65535 |
| `LINEAR_GRADIENT_16bpp.raw` | Full-frame 0→max ramp |
| `LINEAR_GRADIENT_PER_CH_16bpp.raw` | Per-channel 0→max ramp |
| `CHECKERS_16bpp.raw` | 16×40 paxel checkerboard |
| `CHECKERS_INV_16bpp.raw` | Inverted checkerboard |

## Building

```sh
cmake -B build
cmake --build build
```

Test images are generated by running:

```sh
./build/src/apps/img_gen_app
```

Tests:

```sh
./build/test/tests
```
